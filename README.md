# Jolo A. Cañete — Developer Portfolio

A responsive personal portfolio featuring web applications, management systems, prototypes, and Roblox projects. Built with Next.js App Router, React, TypeScript, Tailwind CSS, Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## Deploy on Netlify

Import this repository into Netlify. The included `netlify.toml` configures:

- Build command: `npm run build`
- Publish directory: `.next`
- Node.js: 22
